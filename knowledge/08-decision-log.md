| 37 | The server listens on 127.0.0.1 by default and checks Host and Origin; a network HOST needs STEBULA_TOKEN; STEBULA_PUBLIC=1 serves replay only; live experiments need an explicit call budget with a cap | Paid endpoints must not be open to anyone who can reach the port, and a web page elsewhere must not be able to drive a local server |
