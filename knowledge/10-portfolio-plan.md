# Portfolio plan

## Positioning
"An AI agent lab where every belief the agent holds about itself is recorded, tested against its actual behavior, and open to inspection." Built with Claude. For business audiences: "AI agent with persistent memory, self-correction, and a full audit trail."

## Assets to produce
1. Real data first: 20+ Talk turns, self-prediction tests, one Experiment 01 pilot, the book divergence experiment. Do not show mock data.
2. Public demo on Vercel, replay-only: recorded runs and Talk transcripts, no API cost. Live Talk behind a password for client demos only. Never expose the key.
3. README: screenshots, a 30-second GIF of the brain view during a turn, the results table, the Scorecard.
4. Case study page on ronlenserdigital.com: problem, what it does, real results, honest limits.
5. LinkedIn post built around the best real exchange or the divergence result.

## Best hooks
- The moment it says "your question assumes I feel" and treats its own self-reports as weak evidence.
- Two copies reading different books developing different traits, with provenance, or failing to diverge and revealing the base model.
- Watching it predict its own answer and get it wrong.

## Rules
- Public domain books only for anything published.
- Never claim AGI or consciousness.
- Show the limitations page. It is part of the pitch.
