      Read to Stebula

      It reads in passages of about 200 words. Each passage runs through the brain view, becomes a memory, and may add evidence to its personality model. Reading goes to whichever agent is chosen under Talk.

      Growth

      What grows is Stebula's memory file. The model underneath does not change.

      Left: where it read or talked. Middle: evidence events. Right: traits (teal), motives (gold), beliefs (purple), sized by strength. Green lines support, red dashed lines contradict.

      Traits are evidence-scored patterns, not proof of a personality.

      Compare

      Do two agents that read different things end up with different personalities? An empty-memory copy answers the same five questions, so traits that come from the base model show up in every column.

      Matching is by trait name and kind with loose word overlap, so near-synonyms can be missed. One run is an anecdote.

      Indicator scorecard

      Scientific theories of consciousness each name properties a conscious system should have. This page lists them and says, plainly, which ones the Talk agent implements, in what form, and what is missing.

      Everything on this page is drawn from the recorded event log. Agent statements about feelings or awareness are self-reports, kept as data, not evidence of experience. All change lives in prompts and external memory. Model weights never change.
