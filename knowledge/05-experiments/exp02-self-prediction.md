# Experiment 02: Does Stebula know itself?

Status: BUILT (Talk, "Does it know itself?" panel).

## Design
Stebula predicts whether a fresh copy of itself (same memory, never sees the prediction) will agree, disagree, or be unsure about a statement. Two fresh copies answer. Code scores: both right, one right, neither. Also measures stability: do the two fresh answers agree with each other?

## Questions
- Is self-prediction better than chance (about 33%) and better than always guessing the most common answer?
- Does self-prediction improve as memory grows?
- Does accuracy differ by statement topic (self vs world vs ethics)?

## Watch for
- The "unsure" exploit: always predicting and answering unsure scores well while revealing little. Check the stance distribution.
- Unstable answers make prediction meaningless for that statement.

## Human comparison
Introspective accuracy research (Nisbett and Wilson 1977; Schwitzgebel 2008). Key difference: Stebula's prediction can be checked against a fresh copy with identical memory, which has no human equivalent.
