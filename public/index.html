    Does a stored lesson change the agent's next decision on a new problem?

    Each trial starts from a fresh agent with the same instructions. Only one thing differs: the single lesson in its stored memory. The tasks are the same for every condition, the prediction is recorded before the outcome, and the right answer is held back until scoring.

    Does what an agent receives change the traits it expresses?

    Four agents start identical and differ only in input: reading only, talking only, both, or nothing. At fixed steps each answers the same five questions and takes the same two self-prediction tests. The tests run on a copy of its memory, so they never change the agent being assessed. The prediction and protocol are written down before the first model call.

    Do agents that read different things end up different?

    Agent A and Agent B side by side, plus an empty-memory copy that answers the same five questions. Traits that also appear in the copy likely come from the base model, not from anything read.

    Matching uses trait names with loose word overlap, so near-synonyms can be missed. One run is an anecdote.

    Two agents and a hidden rule

    The original experiment: two agents test a hidden number rule, talk, reflect, and are scored by code against the true rule. Scripted mock agents need no key, and their improvement is built in, so mock results test the plumbing only.

      Architectural indicators

      Scientific theories of consciousness name properties a conscious system might have. This lists them and says which ones Stebula implements, in what form, and what is missing. It is not a score and it is not evidence about experience.

      Everything shown comes from recorded state. Statements an agent makes about feelings or awareness are logged as self-reports, not evidence of experience. All change lives in prompts and stored memory text; model weights never change.
